시나리오를 실행하면 실제 트래픽이 발생하고, 에이전트가 자동으로 버그를 감지/수정합니다

🐍
data-worker
Python FastAPI
🕐 DB Query Timeout
DB_TIMEOUT=1초인데 쿼리가 2.5초 걸림 → 매번 504 Timeout
패치: config.py DB_TIMEOUT = 1 → 30
💥 Batch OOM
BATCH_SIZE=10000 → 메모리 폭증 → OOMKilled
패치: config.py BATCH_SIZE = 10000 → 100
🟢
bff-service
Node.js Express
🔗 Wrong Upstream Port
DATA_WORKER_PORT=9999 (실제: 8000) → 연결 거부 → 502
패치: config.js DATA_WORKER_PORT = 9999 → 8000
⏱️ Upstream Timeout
UPSTREAM_TIMEOUT=500ms인데 응답 2초+ → 타임아웃
패치: config.js UPSTREAM_TIMEOUT = 500 → 10000
🔷
api-gateway
Go
🐢 Proxy Timeout
ProxyTimeout=1초인데 upstream 응답 2초+ → Gateway Timeout
패치: config.go ProxyTimeout = 1s → 30s

core-business
Java Spring Boot
🔌 Connection Pool Exhaustion
HikariCP max-pool-size=1 → 동시 요청 시 500 에러
